# Arena Duel Prototype

Windows x86_64向けの開発中プロトタイプです。GodotエディターやNode.jsは不要です。

## 起動

ZIPを展開して `ArenaDuel.exe` を起動してください。任意で次のコマンドからユーザー領域へインストールできます。

```powershell
powershell.exe -NoProfile -File .\Install.ps1
```

実行ポリシーにより拒否された場合は端末の管理方針に従ってください。インストーラーはポリシーやファイアウォールを変更しません。削除はインストール先の `Uninstall.ps1` で行います。保存データは保持します。

## 操作

| 操作 | キー |
| --- | --- |
| 移動・視点 | WASD・マウス |
| ダッシュ | Shift |
| ジャンプ・乗り越え | Space |
| しゃがみ・ダッシュ中スライド | Ctrl |
| 射撃・ADS | 左クリック・右クリック |
| リロード・拾得 | R・E |
| 銃の交換 | 2丁所持時、対象を見てEを1秒長押し |
| 武器・近接押し返し | 1 / 2・V |
| 回復 | 4短押し、長押しで選択 / 5–8即使用 |
| 投擲 | G短押しで構え、長押しで種類選択 |
| 投げる | 構えて左長押しで軌道、離して投擲 |
| メニュー | Esc |

練習メニューから固定／移動標的の切り替え、リセット、配置再抽選ができます。

## 対戦接続

ホストは相手から到達できる自分のIPを入力し「部屋を作る」を選び、招待コードを相手へ共有します。参加側はそのコードで参加します。招待コードには接続用の秘密が含まれるため、相手へ個別に共有してください。

同じPCでの試験用アドレスは127.0.0.1です。別の家庭からの接続には到達可能なIPとUDP 27840が必要です。Windowsの許可画面は利用者が判断してください。自動ルーター変更は行いません。

直接接続できない場合は、両者が[Tailscaleの公式手順](https://tailscale.com/kb/1015/install)に従って導入・認証・共有を完了し、そのネットワークのホストIPで部屋を作ってください。ゲームは補助ソフトの認証を代行しません。

## 復帰と開発状態

再起動後は「前の試合へ復帰」を選択します。60秒は再試行で延長されません。責任を確定できない通信断は得点を変更せず停止し、記録を残します。外部2家庭の接続検証・利用者の操作感評価は未完了です。詳しい実装・受入状況はソースの docs/implementation-status.md と docs/acceptance-run.md に記録しています。

セーブ先は `%APPDATA%\ArenaDuel\profiles\default` です。招待コード、session保存ファイルは公開しないでください。
